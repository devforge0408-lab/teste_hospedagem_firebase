Como hospedar um site no Firebase App Hosting

O Firebase App Hosting é a solução do Google para hospedar apps web full-stack (Next.js, Angular e backends Node). Siga os passos abaixo — é exatamente o que foi feito com esta landing page.

  1. 1. Instale o Firebase CLI

    npm install -g firebase-tools

  2. 2. Faça login no Firebase

    firebase login

  3. 3. Crie um projeto no Console do Firebase

    Acesse o Firebase Console, crie um projeto e ative o App Hosting (requer plano Blaze — pague apenas pelo que usar).

  4. 4. Conecte seu repositório GitHub

    No console do App Hosting, clique em "Get started", conecte sua conta do GitHub e selecione o repositório do seu site.

  5. 5. Configure o backend

    Defina o nome do backend, a região (ex.: us-central1) e o branch de deploy (ex.: main). O App Hosting detecta o framework e o comando de start automaticamente — para Node puro, ele usa npm start.

  6. 6. Deploy automático

    A cada git push no branch configurado, o App Hosting faz build e deploy automaticamente via Cloud Build + Cloud Run, com CDN, SSL e rollbacks inclusos.

  7. 7. (Opcional) Domínio personalizado

    Na aba de domínios do App Hosting, adicione seu domínio e configure os registros DNS indicados. O certificado SSL é provisionado automaticamente.

💡 Dica: garanta que seu package.json tenha o script "start" e que o servidor escute em process.env.PORT — é assim que o App Hosting sabe como rodar seu app.
